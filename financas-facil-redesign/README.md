# Finanças Fácil

Projeto Front-End para Web (DFEW.08) - Universidade Positivo.

Portal de notícias e educação financeira, desenvolvido com HTML5, CSS3, JavaScript e Bootstrap.

## Como executar

Abra o arquivo `index.html` no navegador. O site funciona offline.

## Estrutura

- `*.html`: páginas do site
- `css/`: estilos
- `js/`: scripts
- `img/`, `audio/`, `video/`: mídias
- `doc/`: documentação
